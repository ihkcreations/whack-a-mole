# Whack A Mole

This application is a playable classic whack a mole game with a timer and score tracker.

## Overview

The application uses JavaScript intervals and timeouts to randomly display moles in holes. Clicking an active mole increments the score before it hides again.

## Highlights

- Interactive grid of holes with popping moles
- Real time score tracking and countdown timer
- Clean desktop application interface
- Keyboard accessible controls and focus rings
